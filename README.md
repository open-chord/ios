# Timplayer

Учебный SwiftUI-клиент для self-hosted музыкального сервиса. Сейчас проект полностью
работает на mock-данных: можно изучать навигацию, поток состояния плеера и
синхронизацию текста, не поднимая backend.

## Запуск

1. Откройте `Timplayer.xcodeproj` в Xcode.
2. Выберите любой iPhone Simulator с iOS 17 или новее.
3. Нажмите Run.
4. Откройте альбом **Afterglow** и включите **Night Drive**.
5. Разверните mini-player и перейдите на вкладку **Lyrics**.

## Как читать проект

- `Domain` — простые модели предметной области без зависимости от UI.
- `Data` — mock-каталог; позднее здесь появятся DTO и GraphQL-репозитории.
- `Playback` — единая точка управления воспроизведением.
- `UI` — экраны, сгруппированные по пользовательским сценариям.

Следующий логичный технический этап — заменить таймер внутри `PlaybackController`
на `AVPlayer`, оставив публичный интерфейс контроллера прежним.
